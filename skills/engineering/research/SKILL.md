Define the question, relevant constraints, and what evidence would change the answer. Match the depth to the request; a routine factual check can be answered directly.

## Research

1. Investigate the question against **primary sources** (official docs, source code, specs, first-party APIs), not a secondary write-up of them. Follow every claim back to the source that owns it.
2. Check source dates, versions, and applicability. Distinguish established facts from inference and unresolved questions; do not equate an unverified claim with evidence.
3. Answer with the conclusion, supporting sources, and material uncertainties. Cite sources close to the claims they support.

Use available Codex subagent tools when independent reading can run in parallel with useful work. Give each agent a bounded question and require source-backed findings. If delegation is unavailable or unnecessary, research directly.

Save findings to a Markdown file only when requested or required by an established project workflow. Use the existing destination and format; otherwise answer in the conversation. Do not create repository documentation merely because research occurred.
